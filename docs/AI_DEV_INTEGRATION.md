# `ai-dev` Technical Engine Integration Contract

`freelance-dev-suite` coordinates the commercial and workflow aspects of freelance jobs, delegating technical codebase analysis to `ai-dev-cli-tools` via its public command-line contract.

---

## 1. Principles of Integration

1. **Strict Boundary**: `freelance-dev-suite` does not implement repository scanners, test runners, git parsers, or context compressors.
2. **Subprocess Invocation**: Integration is performed purely via standard CLI invocations (`subprocess.run`) targeting the `ai-dev` executable.
3. **Structured Machine Output**: All data exchanges parse JSON output generated by `--json` flags on `ai-dev` commands.
4. **Resilience & Fallback**: If `ai-dev` is not installed or returns an error, `freelance-dev-suite` gracefully warns the user and falls back to manual input or safe defaults.

---

## 2. Public CLI Integration Points

### 1. Project Intake Analysis (`freelance analyze`)
- **Action**: Assess repository complexity, dependencies, and risk factors before quoting.
- **Engine Command**:
  ```bash
  ai-dev repo-scan --json
  ```
- **Consumed Payload**:
  - `file_count`: Total managed files in project.
  - `languages`: Language distribution and line counts.
  - `frameworks`: Detected technology stacks.
- **Workflow Result**: Stored in `<job_dir>/analysis/intake.json` to calculate complexity score and recommend contingency margins.

---

### 2. Context Preparation on Session Start (`freelance start`, `freelance work start`)
- **Action**: Generate sliced, token-efficient context for an AI coding agent or freelancer.
- **Engine Command**:
  ```bash
  ai-dev context --profile focused --token-limit 4000 --json
  ```
- **Workflow Result**: Written to `<job_dir>/work/context.md` for immediate consumption in editor or agent prompts.

---

### 3. Session Validation on Work Completion (`freelance work finish`)
- **Action**: Verify that changes made during the session did not introduce syntax errors or broken tests before stopping billable timer.
- **Engine Command**:
  ```bash
  ai-dev validate --json
  ai-dev run-tests --changed-only --json
  ```
- **Workflow Result**:
  - If tests and checks pass: Session marked as `VERIFIED`.
  - If tests fail: Session marked as `FAILED` or `PARTIAL`, logged in session record `<job_dir>/work/sessions/WORK-###.json`.

---

### 4. Client Delivery Quality Gate (`freelance handoff verify`)
- **Action**: Complete pre-delivery validation across test suites and static checks.
- **Engine Command**:
  ```bash
  ai-dev validate --all --json
  ```
- **Workflow Result**: Evaluated by `HandoffChecker` against configured gate requirements (clean working tree, passing tests, documentation present).

---

## 3. Environment & Diagnostic Verification (`freelance doctor`)

The diagnostic command `freelance doctor` validates the availability and version compatibility of the `ai-dev` technical engine:
- Verifies that `ai-dev` is on the system `$PATH`.
- Runs `ai-dev --version` to check that the installed version satisfies `>=1.2.0`.
- Provides remediation commands (`pip install ai-dev-cli-tools`) if missing.
